# Flint build scope

- The user authorized autonomous construction and public release of original BF16 RecursiveSI/flint as Q4_K_M and Q5_K_M under the named webmp3 Sakura repositories.
- Use only public standard ubuntu-24.04 CPU runners and existing HF_TOKEN. No paid resources, GPU, inference API, full source reads in Work, or publication of private builder links.
- Preserve all original architecture components and experts. No Heretic or other weight-editing/abliteration task is included in this release.
- At most one automatic transient retry of failed jobs. Stop on quotas, billing errors, disk limits, failed hashes, or unknown correctness failures.
- Do not change frozen source revisions, native type plans or target IDs to get a passing run.
- The complete publication checkpoint is emitted after native Xet commit and before Hub pointer publication, enabling a separate finalizer to complete the release without model downloads.
